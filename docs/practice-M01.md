## 학습 상태

환경 선택과 작은 기능별 학습 방식은 사용자가 선택했다. 핵심 계약 질문에 대한 사용자 답변이나 직접 코드 작성은 아직 확인하지 않았다. 외부 기초 학습 자료의 26회차 상태와 통합본은 변경하지 않는다.
